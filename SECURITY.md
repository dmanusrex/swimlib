# Security Policy

## Supported versions

Security fixes are provided for the latest published version of SwimLib. Upgrade to the latest
release before reporting a vulnerability that may already have been corrected.

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue. Use GitHub's private vulnerability
reporting form:

<https://github.com/dmanusrex/swimlib/security/advisories/new>

Include the affected version, impact, reproduction steps, and any suggested mitigation. Please
allow the maintainer an opportunity to investigate and prepare a coordinated fix before public
disclosure.

Swimming data files can contain names, birth dates, contact details, medical information, and
other sensitive data. Do not include real athlete or family information in a report. Use a minimal
synthetic example or fully anonymize the file.

Ordinary parsing errors, unsupported records, and format discrepancies that have no security
impact should use the public bug or format-specification issue forms instead.
